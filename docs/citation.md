# Citation

A manuscript describing interpreTFM is in preparation. Until it is published, please cite the software. The repository's `CITATION.cff` holds the same information, and GitHub's "Cite this repository" button exports it.

```bibtex
@software{interpretfm,
  author  = {Hu, Yunfei},
  title   = {{interpreTFM}: layer-resolved evaluation of transcriptomic foundation models},
  version = {0.9.0},
  year    = {2026},
  url     = {https://github.com/OliiverHu/interpreTFM},
  note    = {Manuscript in preparation}
}
```

This page will give the publication reference and an archived release DOI once they exist.

Please also cite the foundation models you analyze (scGPT, Geneformer, C2S-Scale) and the resources used to build concepts (g:Profiler and the annotation sources it queries). The population-specificity measures (GSI, MHR) follow scPISCES.
